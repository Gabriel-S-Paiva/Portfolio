Backend REST API for a municipal support platform (Sistema de Apoio Municipal), handling domain operations, high-frequency logging, and smart locker telemetry.

- Designed the relational schema and UML, and a dual-database architecture: MySQL (Sequelize) for domain entities, MongoDB (Mongoose) for logs and telemetry.
- Built the REST API (MVC architecture, CRUD endpoints) with JWT access/refresh tokens and role-based access control (RBAC).
