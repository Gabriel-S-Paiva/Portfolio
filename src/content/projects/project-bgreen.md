A household sustainability tracker for the Web Programming I course: families log appliance use and green tasks, earn points and badges, and trade points for rewards the parents define. Vue 3 and Pinia against a json-server mock API.

- Wrote the user, tasks and appliances Pinia stores, and the 113 unit tests that cover them.
- Built the admin dashboard, the first-use QuickStart wizard and profile selection with PIN protection.
- The carbon API and the component tests were built by teammates.
