A client-only travel planner covering flights, hotels, and activities, with a gamification layer designed to drive repeat use. Built with an MV architecture persisting to LocalStorage - no backend.

- Built the Model layer: core data logic, seeded datasets (airports, hotels, activities, flights), and `ModelHelpers.js`.
- Designed the gamification system using the HEXAD player-type framework and Werbach's 6D methodology, backed by five researched personas.
- Contributed to UX research and design deliverables: competitor moodboard, wireframes, and brand identity (logo, color system).
